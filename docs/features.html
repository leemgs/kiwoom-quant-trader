핵심 기술 아키텍처

Stock Quant Trader는 단순한 자동화를 넘어선 스마트 금융 프레임워크입니다.

🧠 AI 뉴스 감성 분석

Google Gemini Pro API를 활용하여 실시간으로 쏟아지는 뉴스 제목과 공시 내용을 분석합니다.

  • 초저지연 자연어 처리(NLP)를 통한 호재/악재 판별
  • -100(강력 악재) ~ +100(강력 호재) 점수 산출
  • 단순 차트가 놓치는 재료(Material) 기반의 선제적 대응

⚖️ 전략 앙상블 시스템

하나의 전략은 장세에 따라 실패할 수 있습니다. Stock Quant Trader는 세 가지 상이한 전략을 동시에 운용하여 리스크를 분산합니다.

  • 변동성 돌파: 강한 변동성이 터지는 주도주 추격 매수
  • 평균 회귀: 과매도 구간에서 기술적 반등 포착
  • 추세 추종: 대세 상승장에 올라타는 골든크로스 전략

🛡️ 글로벌 세이프 가드

한국 증시는 미국 증시와 환율에 종속적입니다. 시스템이 스스로 거시 지표를 감시하여 투자 비중을 조절합니다.

  • 나스닥(Nasdaq) 지수 실시간 연동
  • 원/달러 환율 급등 시 매매 자동 축소 및 중단
  • 폭락장에서의 비자발적 손실을 원천 차단

🌐 한·미 다중 마켓 및 공휴일 감지 (Dual-Market & Holiday-Aware)

국내 주식과 미국 주식을 단일 매매 봇에서 유기적으로 거래하며, 불필요한 API 요청과 오작동을 차단합니다.

  • 교차 마켓 거래: 국내 티커(UNIVERSE)와 미국 티커(US_UNIVERSE) 유니버스를 활성 시장 상황에 맞춰 동적 전환
  • 현지 시간 자동 계산: 미국 동부 시각(EST/EDT) 변환을 통한 정규장 거래 시간대(09:30 - 16:00 ET) 감지
  • 휴일 자동 감지: 한국(KR) 및 미국(US) 국가 공휴일을 자동으로 파악하여 불필요한 거래 시도 차단 및 5분 단위 저전력 대기모드 진입

⚡ 스마트 지정가 주문 & 실시간 KIS 시세 API 검증 엔진 (Smart Routing & Zero-Ghost Trades)

실제 증권 계좌 자산과의 오차 및 슬리피지를 원천 차단하는 초정밀 실전 자동매매 코어 엔진입니다.

  • Zero-Ghost Trades 🛡️: KIS Open API 주문 처리 응답코드(rt_cd == '0')를 철저히 검증하여, 실제 체결/접수 완료된 거래만 포지션으로 등록하고 SQLite DB에 기록해 허위 기록 발생을 원천 차단
  • 실시간 KIS 시세 감시 📊: 보유 포지션 감시 시 난수 시뮬레이션을 배제하고 KIS API 실시간 현재가 조회를 통해 실제 시장 가격 기준 정밀 익절(+3.0%) 및 손절(-1.5%) 집행
  • 스마트 지정가 Maker 주문 ⚡: Mojito KIS API의 지정가 매수/매도 API 매칭 인자(symbol, price, quantity 순)를 완벽히 연동하여 실제 호가 슬리피지 방지 및 Maker 수수료 혜택 제공

📈 스마트 모멘텀 추세 전략 & 트레일링 스탑 (Smart Momentum & Trailing Stop)

극단적 초단기 스캘핑 엔진(Extreme Growth)은 더 정교한 이중 필터 진입 시그널과 동적 청산 로직으로 업그레이드되었습니다.

  • 이중 필터 진입 시그널 ⚡: 당일 시가 대비 상승 임계값(breakout_threshold, 기본 1.5%) 돌파와 N회 연속 상승 틱(momentum_ticks, 기본 3틱) 조건을 충족할 때만 진입하여 허수 주문 및 단발성 스푸핑을 필터링합니다.
  • 트레일링 스탑 청산 🛡️: 진입 후 가격 상승에 따라 최고가를 추적하여 스탑 기준가를 갱신하고, 최고가 대비 지정 비율(trailing_stop, 기본 1.5%) 하락 시 즉시 매도하여 수익을 안전하게 확보합니다.
  • 시장가 강제 청산 🔒: 장 마감(15:15) 임박 시 미수금 동결을 방지하기 위해 미체결 주문 취소 후 전 종목을 시장가로 즉시 강제 청산하여 리스크를 원천 통제합니다.

🛡️ KIS API 호출 최적화 및 속도 제한 방지 (API Protection & Caching)

한국투자증권 API의 엄격한 초당 호출 제한(Rate Limit)을 우회하고 시스템의 부하를 최소화하는 이중 보호벽입니다.

  • 공유 잔고 파일 캐시 💳: 대시보드와 자동매매 봇이 공유하는 `data/balance_cache.json`을 통해 30초 단위로 잔고 데이터를 캐싱하여 불필요한 중복 조회를 방지합니다.
  • 구매 불가 종목 쿨다운 ⏳: 실제 예수금보다 현재가가 높아 살 수 없는 종목에 대해 5분 단위의 경고 및 조회 쿨다운 캐시를 적용하여 로그 폭주 및 불필요한 API 호출을 차단합니다.
  • 대시보드 리프레시 완화 ⚡: 실시간 Streamlit 대시보드의 기본 새로고침 간격을 10초에서 30초로 조정하여 API 호출 안정성을 대폭 강화하였습니다.
